# Portal Pengurusan BWI — Government Digital Service UI

Prototaip portal responsif bagi pengurusan Bantuan Wang Ihsan merentas pemohon, JKM, NADMA, BSN dan pentadbir.

## Perubahan reka bentuk

- Logo rasmi NADMA digunakan sebagai aset identiti sahaja.
- Palet warna logo tidak digunakan sebagai tema antaramuka.
- Reka bentuk neutral perkhidmatan kerajaan digital: biru rasmi, putih dan kelabu batu tulis.
- Navigasi, kad, jadual, borang dan status disusun semula untuk paparan operasi yang padat tetapi bersih.
- Interaksi hover, fokus papan kekunci, dialog, penapis, simulasi status dan paparan responsif dikekalkan.
- Modul kawasan bencana, PPS dan jejak transaksi BSN dikekalkan.

## Cara menjalankan

Buka `index.html` dalam pelayar moden. Tiada pemasangan diperlukan.

## Nota

Ini ialah prototaip bahagian hadapan dengan data simulasi. Penggunaan produksi memerlukan backend, integrasi agensi, pengesahan identiti, kawalan akses, keselamatan dan audit sebenar.
